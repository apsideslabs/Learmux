```bash
netstat -tuln
```

```text
Active Internet connections (only servers)
Proto Recv-Q Send-Q Local Address           Foreign Address         State
tcp        0      0 127.0.0.1:8022          0.0.0.0:*               LISTEN
tcp6       0      0 :::8022                 :::*                    LISTEN
```

An address of `127.0.0.1` means the service only accepts connections from this device. An address of `0.0.0.0` or `::` means it accepts connections from anywhere on the network, which is worth knowing. Termux runs its SSH server on port `8022` by default, not the usual `22`, so you connect to it with `-p 8022`.
