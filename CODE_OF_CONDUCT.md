# Code of conduct

## The short version

Be decent. This is a teaching site, so people arrive at different levels and
some of them are wrong about something in public. That is the point of a place
like this, and it is not an invitation to be unkind.

## What is expected

- Assume the person you are replying to is trying to learn or to help.
- Critique the work, not the person. "This command fails on Android 14" is
  useful; "this is obviously broken" is not.
- Be patient with questions that seem basic. You were there once, and the whole
  premise of the project is that basics are worth explaining properly.
- Accept that maintainers have limited time, and a declined pull request is not
  a judgement of you.

## What is not acceptable

- Harassment, insults, or sustained disruption in issues and pull requests.
- Demeaning comments about someone's experience, background, language or
  identity.
- Publishing anyone's private information without their permission.
- Using the issue tracker to post material that is not about this project.

## Scope

This applies to issues, pull requests, commit messages, and anywhere the project
is being represented.

## If something happens

Email the studio at the address on the [contact page](https://apsideslabs.github.io/Learmux/contact/).
Reports are read privately. What happens next depends on what occurred, but it
starts with a conversation and can end with a contribution being removed.

## Credit

This is a short, project-specific code of conduct rather than the Contributor
Covenant, because a document nobody reads protects nobody. It says the same
things in fewer words.
