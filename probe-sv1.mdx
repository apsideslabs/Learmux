```bash
python3 -m http.server 8010
```

```text
Serving HTTP on 0.0.0.0 port 8010 (http://0.0.0.0:8010/) ...
```

Leave it running and go back to your first session. You now have a service on your own device that you can ask about, and it is on a port above 1024, so it needed no root to start.

## Step 2: Ask nmap to identify it

The `-sV` flag asks `nmap` to go beyond naming the port and work out the service and its version. It does this by connecting and reading the greeting the service sends back.

```bash
nmap -sV -n -p 8010 localhost
```
