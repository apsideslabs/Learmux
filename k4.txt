The line reading canonical name is the CNAME. When a service moves, the operator changes the address and leaves the name alone, so you share a name and never hard-code an address.

## Quick reference

| Command | What it does |
| --- | --- |
| `getprop net.dns1` | Prints the DNS resolver your phone uses |
| `dig NAME A` | Asks for the IPv4 address of a name |
| `dig NAME AAAA` | Asks for the IPv6 address |
| `dig NAME MX` | Asks for the mail servers of a domain |
| `dig NAME TXT` | Asks for the text records |
| `dig -x ADDRESS` | Asks for the name behind an address |
