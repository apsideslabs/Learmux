```
; <<>> DiG 9.18.28 <<>> example.com MX
;; Got answer:
;; ->>HEADER<<- opcode: QUERY, status: NOERROR, id: 41031
;; flags: qr rd ra; QUERY: 1, ANSWER: 0, AUTHORITY: 1, ADDITIONAL: 1

;; QUESTION SECTION:
;example.com.                    IN      MX

;; AUTHORITY SECTION:
example.com.            3600    IN      SOA     ns.icann.org. noc.dns.icann.org. 2026011901 7200 3600 1209600 3600
```

Read the flags line. ANSWER: 0 means there is no MX record. This domain publishes no mail servers, so mail sent to it has nowhere to go.

Now the text record:

```
dig +short example.com TXT
```
